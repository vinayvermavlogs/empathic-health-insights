Emotion Nova – Real‑Time Emotion & Health Insights

Description:  
Emotion Detector is a TypeScript‑based platform that combines NLP, computer vision, and AI models to analyze facial expressions, gestures, and sign language in real time. It empowers professionals, learners, and businesses through emotion‑aware interactions, service delivery, and collaborative networking.

Tech Stack:  
TypeScript | React | Vite | Google Gemini Vision API | Supabase | Firebase | MongoDB | Tailwind CSS |

Key Features:

🎭 Emotion Recognition – Detects facial expressions, gestures, and sign language with 92% accuracy. <br>
📊 Health Metrics Integration – Maps emotions to physiological signals (heart rate, HRV, SpO₂, cortisol).<br>
📑 Wellness Reports – Generates professional PDF insights with recommendations.<br>
💬 Real‑Time Collaboration – Emotion‑aware chat, video calls, and shared project spaces.<br>
⚡ Performance – 30% faster emotion retrieval using Google Gemini Vision API and Supabase.<br>
☁️ Deployment – Auto‑deployment on Lovable Cloud with secure environment variable injection.<br>
